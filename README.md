# 星光影业 FlashMovie

网页端电影公司模拟经营游戏 **v0.4.2**。纯前端单机（IndexedDB 本地存档），中文为主 + 英文术语。

**在线试玩**：[https://caiyundc880518.github.io/flashmovie/](https://caiyundc880518.github.io/flashmovie/)

## 运行

需要 Node.js ≥ 20（本机使用 Homebrew 的 node@26，路径 `/opt/homebrew/opt/node/bin`）。

```bash
npm install                 # 若 ~/.npm 权限异常：npm install --cache ./.npm-cache
npm run dev                 # 开发服务器 → http://localhost:5173
npm test                    # 运行规则层单测（vitest，213 项）
npm run build               # 类型检查 + 生产构建（dist/）
npm run preview             # 本地预览生产构建
```

## 架构速览

```
UI 层（React + zustand）        src/ui、src/app
规则层 core（纯 TS 可单测）      src/core
  ├─ types      领域类型
  ├─ config     数值配置表（全部可调）
  ├─ state      状态容器（reducer + 初始状态）
  ├─ rules      纯函数：评分/票房/成长
  ├─ tick       周推进（项目状态机 / 发行生命周期 / IP 长尾结算）
  ├─ generators 员工/剧本生成（种子随机）
  └─ save       存档（IndexedDB + 版本迁移，当前 v15）
```

## 玩法闭环（已实现）

主菜单（输入公司名开始 / 继续游戏）→ 剧本获取（市场购买 / 编剧三档抽卡委托创作）→ 招聘（三档抽卡 · 定向职位 · 一键雇佣）→ 组队立项（5 步向导：选剧本/续作 → 组剧组 → 预算占比 → 特效等级 → 植入广告）→ 拍摄（随机事件 + 运镜小游戏 Buff）→ 剪辑（节奏小游戏）→ 宣发（**单选渠道 + 预热投入 + 主攻地区**）→ **上映（定档提前周数 → 待映预售 → 放映期每周动态票房 → 下片 → 再发行 / IP 长尾）**。未上映项目可随时取消（投入不退，剧组释放回池）。
