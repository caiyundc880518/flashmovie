## 0. 概览（Overview）

### 0.1 一句话概念

《星光影业》是一款网页端的电影公司模拟经营游戏：你是一家电影公司的 CEO，从签下第一个默默无闻的新人编剧开始，招募并培养员工、购买或创作剧本、组建剧组拍摄电影、宣发并发行上映，最终在年度颁奖典礼 TMA 上捧起奖杯，把小作坊经营成电影帝国。

### 0.2 类型与平台

- 类型：模拟经营 / 管理模拟（单人，回合制·周推进）
- 平台：现代浏览器（桌面优先，适配平板）；纯前端单机，本地存档，无后端、无内购、无强制在线

### 0.3 核心体验三支柱

1. **养成**：人才的发现、培养与成名——PA/CA 潜力体系、8 项职业技能、化学反应。
2. **制作**：每部电影从剧本到上映的完整项目制模拟，含轻量小游戏点缀。
3. **商业**：资金、融资、发行渠道、市场竞争与公司扩张。

三线互相驱动，构成游戏的主循环（见 §1.4）。

### 0.4 设计原则

| 原则 | 含义 |
|---|---|
| 决策驱动 | 管理决策是主体，小游戏是点缀而非门槛 |
| 透明数值 | 评分与票房公式可查、可预期，随机波动有边界（≤±10%） |
| 一人一机 | 无强制在线、无内购，存档即世界 |
| 循环验收 | 每一部电影都是对养成成果的一次"验收" |
| 防死局 | 数值上不允许不可逆的破产死局，始终留有翻身手段 |

### 0.5 成功指标（发布阶段）

- 单局可玩 10+ 小时，三线循环自洽
- 数值无崩溃：不出现负收益死局或通胀爆炸
- 核心循环在 15 分钟内被玩家理解（新手引导达标）

## 1. 核心玩法循环（Core Loop）

### 1.1 三层循环结构

- **大循环（多年经营）**：目标是从无名小厂成长为电影帝国。衡量指标：公司市值、声誉、累计获奖数、现金流。每年 4 季度 + 颁奖季（TMA），年末结算与趋势更替。
- **中循环（一部电影，8–20 周）**：筹备（1–4 周）→ 组队（1 周）→ 拍摄（2–8 周）→ 剪辑（1–2 周）→ 宣发（1–4 周，可与剪辑/后期并行）→ 上映结算 → 售后。
- **小循环（每周 tick）**：员工工作推进（技能成长/心情变化/技能衰减）、随机事件与新闻、市场趋势变化；玩家做审批、指派、招募、买剧本、训练、研发、宣发投放等决策。

### 1.2 玩家每周决策清单（小循环）

| 决策类型 | 内容 |
|---|---|
| 人事 | 招募/解雇、培训安排、薪资谈判、项目指派 |
| 项目 | 立项、选剧本、组队、场次调整、宣发投放 |
| 财务 | 融资、预算审批、出售剧本/版权 |
| 经营 | 研发、购置设施、商店消费 |
| 应变 | 处理随机事件（2–3 选 1） |

### 1.3 大循环节奏（一年）

| 周 | 事件 |
|---|---|
| 1–12 | 春季档（Q1）：立项与筹备集中期 |
| 13–26 | 夏季档（Q2）：暑期档票房加成 |
| 27–39 | 秋季档（Q3） |
| 40–48 | 冬季档（Q4）：圣诞档票房加成 |
| 49–51 | 颁奖季：TMA 提名评审（当年第 48 周前上映的影片入围） |
| 52 | 年度结算 + TMA 颁奖典礼 + 新年度趋势刷新 |

### 1.4 三线驱动闭环

```
养成线：招募新人 → 培训/实践 → 技能与 Fame 增长 → 化学反应形成
制作线：剧本 → 组队 → 拍摄 → 剪辑 → 成片(AP/MP) → 上映
商业线：票房/分成收入 → 资金 → 制作成本/薪酬/设施 → 更大规模
        └─────── 资金购买人才与设施 ←────── 商业线产出
```

驱动关系：**商业**提供资金 → 资金购买**人才**与设施 → 人才制作**电影** → 电影产生票房与声誉 → 声誉吸引更强人才与投资人 → 循环升级。

### 1.5 张力与失败面

- 资金不足：被迫卖剧本/裁员/接低质合约
- 人事压力：员工心情、成名后加薪要求、技能衰减
- 竞争压力：竞争对手抢占档期与市场
- 风险决策：贷款杠杆、赌冷门艺术片、接受植入广告

## 2. 时间与日历（Time & Calendar）

- **时间单位**：周（1 周 = 1 tick）；一年 = 12 个月 = 52 周。
- **月度结算**：每月第 1 周处理薪酬、贷款利息、办公成本。
- **年度结算**：第 52 周，含 TMA 颁奖与新年趋势刷新。
- **档期加成**：暑期档、圣诞档影片票房系数加成（示例 +15%）。
- **趋势周期**：每年刷新 1–2 次潮流类型（如"本年度动作片流行"），与剧本 Trend 属性联动。
- **时间成本表**（示例，全部走配置表）：

| 动作 | 耗时（周） |
|---|---|
| 签约编剧产出剧本 | 3–6 |
| 拍摄 | 场次数 × 2 ± 团队效率修正 |
| 剪辑 | 1–2 |
| 宣发 tour | 1–4（可与剪辑并行） |
| 一部标准电影全周期 | 约 8–20 |

- **多项目并行**：公司可同时进行多个项目，受员工数量与资金约束，形成资源分配决策。

## 3. 电影生命周期（Film Lifecycle）

> 本节是文档主线。每小节含：设计意图、流程、关键机制、玩家决策点、版本归属（V1/V2/V3，见 §10）。

### 3.1 筹备（Preparation）

**设计意图**：每部电影的"选题与买单"环节，决定本片的天花板。

**剧本获取三来源**：

| 来源 | 说明 | 版本 |
|---|---|---|
| 剧本市场购买 | 即时可用，质量与价格正相关；Fame Point 越高，越知名的编剧/剧本会主动找上门 | V1 |
| 签约自由编剧 | 按周产出剧本，可指定类型/方向；成本低但有失败率（可能产出低质剧本） | V1 |
| 自建写作学校 | 长期投资培养自家编剧，产出剧本可自用也可出售 | V2 |

**剧本属性**（8 项）：

| 属性 | 含义 |
|---|---|
| Type | 类型：Comedy / Horror / Action / Love / War 等 |
| Story Point | 故事强度，定义制作难度 |
| Artistic Potentials | 艺术潜力，影响 TMA 机会 |
| Market Potentials | 市场潜力，影响最终销售 |
| Fame Point | 越高，越知名的人才会主动联系你 |
| Trend | 与当前潮流类型的契合度 |
| Scale | 需要的团队规模与舞台数（Stage 数） |
| Script-Requirement | 对演员性别/年龄/经验、舞台风格的要求 |

**融资来源**：

| 来源 | 机制 | 版本 |
|---|---|---|
| 自有资金 | 无成本，受现金约束 | V1 |
| 银行贷款 | 有利息（示例 8%/年），额度与年收入挂钩 | V1 |
| 投资人 | 提供资金，分成 30–50%，可能干预决策 | V2 |
| IPO | 上市融资，解锁大规模扩张 | V3 |

**立项流程**：选剧本 → 评估预算（Scale 决定成本区间）→ 资金确认 → 进入组队。

**玩家决策点**：买剧本还是养编剧？贷款加杠杆还是稳健经营？拍流行类型跟风还是赌冷门艺术片？

### 3.2 组建剧组（Team Building）

**设计意图**：把"人才"转化为"项目"，选角匹配与化学反应决定拍摄上限。

- **9 职位**：Producer / Director / Writer / Actor / Shooter / Editor / Technician / Market / Assistant。
- **雇佣方式**：外聘（一次性项目合约，贵、无长期价值）或自家员工（有成长，占用长期资源）。
- **职位职责**（详见 §4.1）：
  - Producer：寻找更优剧本与档期、节省制作成本
  - Director：带队，决定最终 AP/MP 导向；可自动生成场次分配
  - Actor：贡献 Acting 分，需匹配剧本要求（性别/年龄/经验）
  - Shooter / Editor / Technician / Market：按职业技能贡献对应分项
  - Assistant：自动化日常（训练安排、财务报告、季度总结）
- **选角匹配**：剧本 Script-Requirement vs 候选人属性，UI 显示匹配度与预算红线。
- **化学反应**（V1 简化 / V2 完整）：成员相性（性格 × 风格 × 历史合作）影响拍摄效率与成片质量；长期合作形成"黄金组合"加成。
- **玩家决策点**：省钱用新人还是贵价用熟手？外聘即战力还是培养自家员工？

### 3.3 拍摄（Shooting）

**设计意图**：把剧本变成"素材"，是预算消耗与质量波动的主要来源。

- **场次分配（Stage Allocation）**：剧本按 Scale 拆分为若干 Stage，每个 Stage 分配演员与场景；Director 可自动生成，玩家可手动调整。
- **VFX 设置**（V2 完整 / V1 简化）：选择 VFX 技能与团队、VFX 预算占全片比例滑块——占比越高成本越高，但 VFX 分越高，且对动作/科幻等类型加成更明显。
- **植入广告（In-Movie Ad）**：接受广告植入换取资金，代价是 AP 降低/观感扣分（平衡决策）。
- **随机事件**：演员问题（生病/绯闻/罢演）、导演问题（意见分歧）、VFX 问题（预算超支/工期延误）、化学反应问题（内讧）、随机新闻（利好/利空）、趋势突变。每个事件给出 2–3 个选项，影响金钱/士气/成片参数。
- **拍摄小游戏（Shooter Buff）**：每部电影拍摄 2–4 次轻量小游戏（节奏/时机点击，如"运镜时机"）。成功 → 拍摄分增益与士气提升；失败 → 轻微减益。V1 只做最简单的单键时机版本，V2 加深度。

### 3.4 剪辑（Editing）

**设计意图**：成片的"塑形"，决定最终分数的分配方向。

- **剪辑小游戏（Editor Buff）**：选择"市场向"（对观众更友好）或"艺术向"（艺术加分）剪辑风格；小游戏表现给对应方向 Buff。V1 简化为二选一 + 数值结算，V2 加入节奏小游戏。
- **成片预览**：结算前展示各分项预测（Story / Music / Edit / Acting / Shooting / Directing + VFX），让玩家预判 AP/MP 走向。

### 3.5 宣发（Advertising）

**设计意图**：把成片"卖出去"的第一步——控制 Hype，影响首周票房。

- **宣发 tour**：Market 员工执行多轮宣发动作（预告片 / 路演 / 媒体投放），每轮消耗预算与时间。
- **Hype**：上映前热度，由 Market/Advertise 技能、宣发投入、Trend 契合度、演员 Fame 共同决定。Hype 高 → 首周票房系数高；Hype 低 → 上映即遇冷。
- **趋势引导（Trend Lead）**：宣发可引导或蹭当前潮流类型。
- **版本**：V1 简化为"宣发预算滑块 + 一次投放"；V2 完整宣发 tour。

### 3.6 发行与销售（Publishing & Sale）

**设计意图**：选择"怎么卖"，决定收入结构与分成。

- **自发行 vs 发行商**：自发行拿全部收入但承担全部风险（档期/排片能力弱）；发行商出钱出渠道但抽成。Publish Contract 包含预付款与分成比例谈判。
- **五渠道**：

| 渠道 | 说明 | 版本 |
|---|---|---|
| Cinema 影院 | 首轮主收入，受排片率/档期影响 | V1 |
| Web 网络 | 线上播映 | V2 |
| DVD | 实体/数字介质销售 | V2 |
| Streaming 流媒体 | 平台买断/分成 | V2 |
| Free 免费 | 换取观众基数与口碑 | V3 |

- **影院收入**：排片率 × 上座率 × 票价 × 放映周数；排片率与院线关系（§6）挂钩。
- **版本**：V1 仅影院（简化系数），V2 五渠道完整。

### 3.7 结算与复盘（Settlement）

**设计意图**：验收与反馈，把结果写回养成与商业线。

- **票房与收入**：按 §7.3 公式结算票房，汇总各渠道分成 → 财务报表。
- **最终评分构成**：基础分六项（Story / Music / Edit / Acting / Shooting / Directing）+ VFX 分 + Specific（自动生成的特色属性，由员工属性/随机事件/市场需求组合产生）+ 化学/小游戏 Buff。
- **Group Performance**：每位成员在本片的工作成绩单（分项贡献 + 实时表现）。高绩效提升 TMA 获奖机会、个人 Fame 与身价。
- **员工反馈**：技能经验增长、心情变化、成名后薪资谈判。
- **版本**：V1 全做（简化公式）。

### 3.8 售后与 IP（Post Sale）

**设计意图**：长线收益与系列化。

- **衍生**：周边授权、画廊（Gallery）收入。
- **IP 概念**：高票房/高口碑作品沉淀为 IP，续作获得基础观众加成与投资溢价；IP 资产在 §5 公司管理中维护。
- **版本**：V3。

## 4. 员工系统（Workers）

### 4.1 职位与职责（9 职位）

| 职位 | 一句话职责 | 核心技能 | 对成片的贡献 |
|---|---|---|---|
| Producer 制片 | 找好剧本、谈好价钱 | —（被动） | 降低制作成本、提升剧本供给质量 |
| Director 导演 | 带队、定 AP/MP 导向 | Direct | Directing 分；决定最终评分取向 |
| Writer 编剧 | 产出剧本 | —（剧本侧） | 剧本属性决定电影天花板 |
| Actor 演员 | 出演、贡献人气 | Act | Acting 分 + 票房人气 |
| Shooter 摄影 | 控制镜头 | Shoot | Shooting 分；小游戏增益载体 |
| Editor 剪辑 | 让成片可看 | Edit | Edit 分；剪辑 Buff |
| Technician 技术 | 升级设备/VFX 技能 | Technical | 解锁更高制作规模与 VFX |
| Market 市场 | 扩张市场、谈发行 | Market / Advertise | Hype、发行渠道、最终 MP |
| Assistant 助理 | 自动化日常 | —（被动） | 训练安排、财务报告、季度总结 |

### 4.2 属性体系（四层 + 履历）

**基础属性**：

| 属性 | 说明 |
|---|---|
| Name / Age / Gender | 基础信息 |
| Height / Weight | 形象数据（部分剧本要求） |
| Main Type | 主类型：与角色/剧本类型匹配（如"硬汉"适合动作） |
| PA（Potential Ability） | 潜力上限，决定 CA 成长天花板 |
| CA（Current Ability） | 当前综合能力 |
| Fame | 知名度：影响票房、身价、主动接触的剧本/人才 |
| Hype | 热度：近期媒体热度，影响票房与宣发 |

**精神属性**：Intelligence（智力：学习速度）、Focus（专注：质量稳定性）、Gift（天赋：成长速率）、Dedication（敬业：心情恢复/衰减）、Leader（领导：团队效率）、Adaptability（适应：类型转换代价）、Versatility（全能：可胜任多职位）。

**身体属性**：Strong（体能：长时间工作）、Agility（敏捷：小游戏表现）、Initiative（主动性：随机事件正面概率）、Disease（体质：生病事件概率）、Charisma（魅力：观众缘）、Sexy（性感：特定类型加成）。

**活跃属性**：Mood（心情：效率与事件概率，受工作/休息/待遇影响）、Volume（精力：每周可投入工时）。

**履历属性**：Career History（职业履历：参与过的项目与表现）、Award History（获奖履历：TMA/行业奖项）。

### 4.3 职业技能（8 项）

| 技能 | 作用 | 提升方式 |
|---|---|---|
| Act Skill | Acting 分 = Act × 工时 | 出演实践、学校 |
| Direct Skill | Directing 分 = Direct × 工时 | 执导实践、学校 |
| Shoot Skill | Shooting 分 = Shoot × 工时 | 拍摄实践、学校 |
| Edit Skill | Editing 分 = Edit × 工时 | 剪辑实践、学校 |
| Market Skill | 影响 Market Point 与 Hype | 宣发实践、学校 |
| Technical Skill | 科技更新速度、制作规模 | 学校（花钱） |
| Advertise Skill | 宣发规模/效果、最终 Market Point | 学校（花钱） |
| VFX Skill | VFX 分、最终 Market Point | 项目实践、学校 |

### 4.4 成长与衰减

- **项目实践**：参与项目后按贡献获得经验（Post-Project Buff）；能力累积达阈值 → 升级（解锁更高 Scale 岗位、更高薪酬）。
- **Post-Scripting Buff（编剧）**：编剧完成剧本后能力提升，能力达阈值升级。
- **学校培训**：花钱定向提升技能（Technical / Advertise 等）。
- **衰减**：长期不工作（示例：连续 8 周）技能与 Fame 开始下滑。
- **潜力路线**：高 PA 低 CA 的新人（便宜、培养周期长、成才回报高）vs 高 CA 熟手（贵、即战力）。这是养成线的核心取舍。

### 4.5 化学反应（V2）

- 成员相性评分（性格 × 风格 × 历史合作），影响拍摄效率与成片质量。
- 长期搭档形成"黄金组合"：固定加成 + 特殊事件解锁。
- V1 仅实现简化相性（同类型风格加成），不做完整系统。

### 4.6 员工 UI

- **列表页**：卡片展示立绘、职位、CA/PA、薪资、心情、当前项目。

## 7. 数值模型（Numeric Model）

### 7.1 设计原则

- 全部数值走配置表（JSON），实现期可调；本 GDD 只给结构与示例值。
- 每项评分 = 基础贡献 × 修正系数 × 随机波动（波动 ≤ ±10%）。
- 乘算前先归一化，防止数值爆炸。

### 7.2 成片评分

```
分项分 = 对应技能均值（职位 × 工时加权）× 化学系数 × 小游戏Buff × 随机波动
基础分 = Σ(六项分 × 权重)
VFX 分 = VFX预算占比 × VFX技能均值 × 类型系数
Specific = 属性组合/随机事件生成的特色加成（示例："群像戏 +20"）
```

**评分构成示例权重**（可调）：

```
S = 0.30×Story + 0.20×Directing + 0.20×Acting
  + 0.15×Shooting + 0.10×Edit + 0.05×Music
  + VFX(0~15) + Specific(0~10) + Buffs
```

**AP / MP**：

```
AP = 艺术向加权（Story、Artistic Potentials、Directing、Shooting）
MP = 市场向加权（Market Potentials、Acting 人气、Hype 折算）
```

### 7.3 票房

```
首周票房 = 排片率 × 上座率系数 f(Hype, MP, Trend, 档期) × 票价 × 影院数
总票房   = 首周票房 × 长尾衰减曲线（口碑 f(AP) 决定长尾）
分渠道系数（示例）：影院 1.0 / 网络 0.6 / DVD 0.3 / 流媒体 0.5
发行商模式：预付款 + 分成比例（分成 20–50% 按谈判）
```

### 7.4 员工成长

```
经验   = Σ(项目贡献 × 项目规模系数)
技能点 = 经验 × 学习系数（Gift / Intelligence 修正）
衰减   = 连续 N 周不工作，技能与 Fame 每周 -X%
CA 上限由 PA 决定；升级阈值按曲线配置
```

### 7.5 经济平衡

- 中等规模电影成本基准 = 1.0，预期票房 0.8–1.6（盈亏取决于决策质量）。
- 贷款：利率 8%/年（示例），额度 = 年收入 × 2（示例）。
- 投资人：资金注入，分成 30–50%，可能干预决策。
- **防死局**：破产保护——允许出售剧本/版权/资产救急；最低限度保留"接外包合约"保命选项。

## 8. 技术方案（Technical）

- **形态**：纯前端单机，静态站点部署，浏览器直接运行，无后端。
- **存档**：IndexedDB；存档 = 整个游戏状态对象，带版本号，升级时迁移。
- **分层架构**：

```
UI 层（框架渲染，只读状态 + 派发 action）
   ↓ action
规则层（纯函数：计算、随机、tick 推进，可单测）
   ↓ 状态
数据层（纯状态 + 序列化/存档）
```

- **时间推进**：周 tick 由规则层驱动，每个 tick 输出事件列表 → UI 呈现。
- **技术栈约束**：TypeScript；前端框架 React/Vue 任选；状态管理轻量（zustand / pinia）；构建 Vite；无运行时后端依赖。具体选型在架构阶段确定。
- **性能目标**：员工与事件数据驱动，UI 增量渲染；存档体积 < 5MB。

## 9. 美术与 UI（Art & UI）

### 9.1 风格定位

- 扁平编辑风：干净栅格、大信息密度、编辑式的排版。
- 主色调建议：深蓝底 + 金色点缀（影视行业感）；辅以类型色（动作红/恐怖紫/爱情粉等）。
- 字体：中文优先，标题衬线化强化"片场"气质（实现期定字体）。

### 9.2 视觉表现

- **海报卡片**：每部电影自动生成风格化海报（类型 × 主题色 × 主演立绘拼贴），贯穿立项到结算全流程。
- **员工立绘**：扁平插画头像，随 Fame/年龄微调（发型/服饰变化）。
- **成片表现**：海报 + 片段动画演示（剧情梗概卡片流）。

|---|---|

- 轻量过渡动画，不打断操作节奏；关键反馈（票房大卖/获奖）允许仪式感演出。

## 10. 路线图（Roadmap）

> 正文各节已标注版本归属。版本定义如下：

| 版本 | 范围 | 验收标准 |
